Agent Loop 模块

ReAct = Reasoning + Acting
自己反复思考 → 决定工具 → 执行 → 再思考 → 完成
用户消息 → AgentLoop 分发 → Runner 执行思考 → 调用工具 → 再思考 → 结束应答 for iteration in range(max_iterations): ├─ _request_model() ← 调 LLM ├─ 有 tool_calls？ │ ├─ YES → 执行 → append → continue │ └─ NO → break

Subagent 后台任务

SpawnTool.execute() └─→ SubagentManager.spawn() └─→ asyncio.create_task(_run_subagent()) ├─ ToolRegistry 注册工具（不含 spawn/message） ├─ _build_subagent_prompt() ├─ AgentRunner.run() └─ _announce_result() → MessageBus 通知主 agent

关键特性

  • 非阻塞：立即返回
  • 后台独立运行
  • 完成后通知主agent

设计限制

  • 单层派生（不可嵌套）
  • 无spawn/message工具
  • 避免任务树爆炸
