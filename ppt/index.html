Agent Loop · 核心概念
04 / 28
概念定义 · Definition

什么是 Agent Loop?

普通 AI：问一句答一句

问答之间没有连续性，每次对话独立结束

Agent 系统：目标驱动循环

给一个目标 → 思考 → 用工具 → 再思考 → 循环直到完成

"Agent Loop 会自己反复思考、自己决定要不要用工具、用什么工具、看结果、再思考，一直循环到它认为任务完成为止。"
— ReAct = Reasoning + Acting
